# Источник значений для enum'ов контракта

Контракт заводит **свои** backed string enum'ы (`AnimeType`, `Demographic`,
`GenreCode`, `ThemeCode`, `SyncStatus` и т.п.) для полей, которые являются
закрытыми словарями — вместо `string`, чтобы не терять типобезопасность,
но и не тянуть зависимость на хост-приложение (см. `MUST NOT` в
`CLAUDE.md`).

Значения этих enum'ов должны совпадать 1:1 с одноимёнными enum'ами
хост-приложения, но проверить это, не имея доступа к репозиторию хоста в
текущем окружении, не выйдет — `anime-db-plugin-contracts` не содержит
исходников хоста.

Хост-приложение (desktop) в рабочем окружении лежит в отдельном чекауте:

```
/var/www/anime-db-workspace/docs/anime-db-desktop/app/src/Entity/Enum/
```

Перед тем как заводить/менять enum контракта под значения хоста —
свериться с исходником там (например, `AnimeType.php`, `Demographic.php`,
`GenreCode.php`, `ThemeCode.php`), а не гадать/брать из внешних
источников (типа стандартной таксономии MAL) — они могут разойтись.
